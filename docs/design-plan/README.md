# Design Plan Convention

This folder holds dated, permanent records of significant design/planning
sessions — not ephemeral notes. Each entry documents a decision and the
reasoning behind it, so future sessions (human or agent) can see the history
without re-deriving it.

**Naming**: `YYYY-MM-DD-short-topic.md`

**Keep, don't delete**: once merged, these files stay as historical record
even after the work they describe ships.

This folder starts empty in the template — the first entries get created by
whoever uses this template for their first real design session.
